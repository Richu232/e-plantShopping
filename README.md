# e-plantShopping

## Paradise Nursery Shopping Application
An interactive React application for shopping unique houseplants categorized into unique selections.

### Features Implemented
- Dynamic Landing interface with active route transition triggers.
- Multi-category custom catalog layouts using flexible product structures.
- Global client state structures handled with @reduxjs/toolkit.
- Live context update indicators supporting direct addition, structural decrementing triggers, complete cart deletions, and runtime pricing analytics.
